## 1. 注册飞书机器人

### 1.1 创建飞书应用

1. 打开 https://open.feishu.cn ，用飞书账号登录
2. 点击「创建企业自建应用」
3. 填写应用名（如"AI 新闻助手"）、描述，点击创建

### 1.2 添加机器人能力

1. 进入应用详情页 → 「添加应用能力」→ 选择「机器人」
2. 配置机器人名称和描述，点击保存

### 1.3 开通权限

1. 进入「权限管理」，搜索并开通以下权限：
   - `im:message:send_as_bot` — 以应用身份发消息
   - `im:message:readonly` — 获取单聊、群组消息
   - `im:chat:readonly` — 获取群组信息
   - 如有其它推荐权限，也一并开通

2. 右上角「创建版本」→ 「发布」（务必发布，否则权限不生效）

### 1.4 获取 App ID 和 App Secret

1. 进入「凭证与基础信息」
2. 复制 **App ID** 和 **App Secret**，后面要用

## 2. 获取 DeepSeek API Key

DeepSeek 是给新闻写摘要的 AI 模型，便宜好用。

1. 打开 https://platform.deepseek.com
2. 注册/登录（可用微信扫码）
3. 进入「API Keys」→ 点击「创建 API Key」
4. 复制生成的 Key（格式 `sk-xxx`），**妥善保存，只显示一次**

> 💰 费用参考：每天处理 100 篇文章约 ¥0.005，一个月不到 ¥0.2

## 4. 配置 GitHub Secrets

Secrets 是 GitHub 的安全存储功能，用来放 API Key 等敏感信息，不会暴露给其他人。

### 4.1 进入设置

1. 在你 Fork 的仓库页面 → 点击 **Settings**
2. 左侧菜单 → **Secrets and variables** → **Actions**
3. 点击 **New repository secret**，逐条添加以下 4 个 Secret：

| Name（名称） | Value（值） | 说明 |
|---|---|---|
| `FEISHU_APP_ID` | `cli_xxx` | 飞书 App ID（第 1 步获取的） |
| `FEISHU_APP_SECRET` | `xxx` | 飞书 App Secret（第 1 步获取的） |
| `FEISHU_CHAT_ID` | `ou_xxx` 或 `oc_xxx` | 推送目标（你的 open_id 或群聊 chat_id） |
| `DEEPSEEK_API_KEY` | `sk-xxx` | DeepSeek Key（第 2 步获取的） |

> 💡 **如何获取 open_id？** 在飞书里搜索你的 Bot 名称 → 发一条私聊 → 联系管理员在飞书后台查看通讯录用户列表。或者直接在飞书客户端里，你的个人资料页面可能有 ID 信息。

把 `FEISHU_CHAT_ID` Secret 先设为你的 open_id（格式 `ou_xxx`），这样推送只发到你自己私聊。后续想改到群聊时换成群聊的 chat_id（格式 `oc_xxx`）即可。

## 5. 测试首次推送

1. GitHub 仓库页面 → 点击 **Actions**
2. 左侧选择 **Daily AI News Digest**
3. 点击 **Run workflow** → **Run workflow**
4. 等待约 3-5 分钟
5. 去飞书看是否收到了新闻卡片

项目默认**每天北京时间上午约 6:00 触发**（缓冲 GitHub 延迟后约 10:30 到达）。

## 6. 配置私聊 Bot（可对话调整）

推送跑通了，但每次改配置都要改代码？不用。装一个 Bot，在飞书私聊里直接聊天就能调整推送。

### 6.1 它能做什么

在飞书私聊里对 Bot 说：

| 你说 | Bot 做 |
|---|---|
| **"推送一份"** | 立刻抓取 + 推送最新新闻 |
| **"AI4S 多一篇"** | 自动修改配额 4→5 |
| **"通用 AI 少一篇"** | 自动修改配额 2→1 |
| **"AI4S 3篇 通用 3篇"** | 直接设具体数字 |
| 其他消息 | DeepSeek 分析后回复 |

### 6.2 怎么跑

Bot 需要在电脑上持续运行（或部署到云服务器）。在项目目录下：

```bash
# 1. 创建本地密钥文件（不会上传到 GitHub）
echo 'FEISHU_APP_ID=cli_xxx
FEISHU_APP_SECRET=xxx
DEEPSEEK_API_KEY=sk-xxx' > .env.bot

# 2. 安装依赖
pip install -r requirements.txt

# 3. 启动 Bot（后台运行）
source .env.bot && python3 scripts/bot_listener.py &
```

### 6.3 需要额外的飞书权限

在飞书开放平台开通：
- `im:message:readonly` — 读取私聊消息
- `im:message:send_as_bot` — 发送回复

## 7. 新闻来源说明

当前系统从 **13 个来源** 抓取新闻，全部自带真实发布日期，严格限制昨天一天。

### AI for Science 来源

| 来源 | 方式 | 说明 |
|---|---|---|
| Nature | RSS | 顶级科学期刊，AI 关键词过滤 |
| MIT News | RSS | MIT 人工智能频道 |
| Meta AI Research | RSS | Meta 基础 AI 研究 |
| Google DeepMind | RSS | DeepMind 官方博客 |
| Microsoft Research | RSS | 微软研究院 |
| Arxiv | API | cs.AI/CL/LG/CV + 生物/材料/化学 |

### 通用 AI 来源

| 来源 | 方式 | 说明 |
|---|---|---|
| OpenAI Blog | RSS | OpenAI 官方博客 |
| The Verge / TechCrunch / VentureBeat | RSS | 英文 AI 科技媒体 |
| AI Hot | 公开 API | 高质量聚合 AI 新闻，自带中文摘要 |
| 36Kr / GitHub Trending / AP News | RSSHub | 中文快讯 / 开源趋势 / 英文综合 |

### 日期严格性

- **只保留昨天的新闻**，多一天都不要
- **无日期的文章一律丢弃**，不编造
- 所有 RSS/API 源自带真实发布日期

## 8. 常见问题

### Q: 推送内容包含很久以前的旧新闻？

A: 不会。系统已配置为**严格只推送前一天**的新闻，日期窗口为 0 天。

### Q: DeepSeek API 报错？

A: 检查 `DEEPSEEK_API_KEY` Secret 是否正确填写，确认账户有余额。

### Q: 飞书收不到消息？

A: 
1. 检查 Bot 是否已发布（飞书后台 → 创建版本 → 发布）
2. 检查 `FEISHU_CHAT_ID` 是否正确
3. 检查 `im:message:send_as_bot` 权限是否已开通

### Q: 想改推送时间和数量？

A: 
- **推送时间**：编辑 `.github/workflows/daily-digest.yml` 中的 `cron`
- **推送数量**：编辑 `config.yaml` 中的 `max_articles_for_primary_card`
- **AI4S/通用AI比例**：编辑 `main.py` 中 `_select_diverse` 函数的配额
- 或者直接**飞书私聊对 Bot 说**（见第 6 步）

### Q: Bot 不回复？

A: Bot 需要在电脑上持续运行（`python3 scripts/bot_listener.py`），关掉终端就停了。需要 24 小时在线的话，部署到云服务器上。
