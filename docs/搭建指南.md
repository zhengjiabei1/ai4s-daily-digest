## 1. 注册飞书机器人

### 1.1 创建飞书应用

1. 打开 https://open.feishu.cn ，用飞书账号登录
2. 点击「创建企业自建应用」
3. 填写应用名（如"AI 新闻助手"）、描述，点击创建

### 1.2 添加机器人能力

1. 进入应用详情页 → 「添加应用能力」→ 选择「机器人」
2. 配置机器人名称和描述，点击保存

### 1.3 开通权限

1. 进入「权限管理」，搜索并开通以下权限：
   - `im:message:send_as_bot` — 以应用身份发消息
   - `im:message:readonly` — 获取单聊、群组消息
   - `im:chat:readonly` — 获取群组信息
   - 如有其它推荐权限，也一并开通

2. 右上角「创建版本」→ 「发布」（务必发布，否则权限不生效）

### 1.4 获取 App ID 和 App Secret

1. 进入「凭证与基础信息」
2. 复制 **App ID** 和 **App Secret**，后面要用

## 2. 获取 DeepSeek API Key

DeepSeek 是给新闻写摘要的 AI 模型，便宜好用。

1. 打开 https://platform.deepseek.com
2. 注册/登录（可用微信扫码）
3. 进入「API Keys」→ 点击「创建 API Key」
4. 复制生成的 Key（格式 `sk-xxx`），**妥善保存，只显示一次**

> 💰 费用参考：每天处理 100 篇文章约 ¥0.005，一个月不到 ¥0.2

## 4. 配置 GitHub Secrets

Secrets 是 GitHub 的安全存储功能，用来放 API Key 等敏感信息，不会暴露给其他人。

### 4.1 进入设置

1. 在你 Fork 的仓库页面 → 点击 **Settings**
2. 左侧菜单 → **Secrets and variables** → **Actions**
3. 点击 **New repository secret**，逐条添加以下 4 个 Secret：

| Name（名称） | Value（值） | 说明 |
|---|---|---|
| `FEISHU_APP_ID` | `cli_xxx` | 飞书 App ID（第 1 步获取的） |
| `FEISHU_APP_SECRET` | `xxx` | 飞书 App Secret（第 1 步获取的） |
| `FEISHU_CHAT_ID` | `ou_xxx` 或 `oc_xxx` | 推送目标（见第 5 步） |
| `DEEPSEEK_API_KEY` | `sk-xxx` | DeepSeek Key（第 2 步获取的） |

## 5. 配置推送对象

先推送给你自己测试，确认没问题后再改到群聊。

### 5.1 私聊测试

先把 `FEISHU_CHAT_ID` Secret 设为你的 open_id。

**如何获取你的 open_id？**

你的飞书应用已经在「权限管理」中开通了 `contact:contact.base:readonly`。在项目的 `scripts/` 目录下有 `find_chat_id.py` 脚本，运行它可列出 Bot 能访问的所有用户。但这需要在本地运行项目——如果还未安装本地环境，先跳到第 6 步看 Actions 自动运行。

最简方式：在飞书里搜索你的 Bot 名称 → 发一条私聊 → Bot 的 Secret 里暂时用任意值 → 第 6 步手动触发后，Bot 会往那个"任意值"发——但不对。正确方式：

1. 确保 Bot 已经发布并上线
2. 在飞书里搜索机器人的名称，给它发一条"你好"
3. 机器人收到私聊后，你可以通过管理员后台查到 open_id

如果你是本企业管理员，更简单：

1. 在飞书开放平台 → 应用的「安全设置」页面，确保「可用性」设置为「全体成员」
2. 你的 open_id 格式为 `ou_xxxx`，可在飞书通讯录 API 或直接联系管理员获取

> 💡 **终极简单方式**：创建一个测试群，把机器人拉进去，用群聊的 chat_id（格式 `oc_xxx`）。通过脚本 `find_chat_id.py` 可获得。

### 5.2 改成群聊推送

测试通过后，把 `FEISHU_CHAT_ID` Secret 改成群聊的 chat_id：
- 格式 `oc_xxx`：群聊 ID
- 格式 `ou_xxx`：个人 open_id

机器人需要被拉入目标群聊才能发送消息。

## 6. 测试首次推送

### 6.1 手动触发

1. GitHub 仓库页面 → 点击 **Actions**
2. 左侧选择 **Daily AI News Digest**
3. 点击 **Run workflow** → **Run workflow**
4. 等待约 3-5 分钟

### 6.2 检查结果

1. 去飞书看是否收到了新闻卡片
2. 如果没有，回到 Actions 页面，点击最新的运行记录 → 展开 **Run daily news digest** → 查看错误日志

### 6.3 定时推送

项目默认配置为**每天北京时间上午 10:30 左右**自动推送。

> ⚠️ GitHub Actions 的免费版定时触发可能有 1-4 小时延迟，属于正常现象。

## 7. 常见问题

### Q: 推送内容包含很久以前的旧新闻？

A: 系统已配置为**严格只推送前一天**的新闻，旧新闻会被自动过滤。

### Q: DeepSeek API 报错？

A: 检查 `DEEPSEEK_API_KEY` Secret 是否正确填写，确认 https://platform.deepseek.com 账户有余额。

### Q: 飞书收不到消息？

A: 
1. 检查 Bot 是否已发布（飞书后台 → 创建版本 → 发布）
2. 检查 `FEISHU_CHAT_ID` 是否正确
3. 检查 Bot 是否在目标群聊中
4. 检查 `im:message:send_as_bot` 权限是否已开通

### Q: 如何更换推送的新闻来源？

A: 编辑仓库中的 `config.yaml` 文件，在 `sources` 下增删 RSS 源。修改后提交，下次推送自动生效。

### Q: 想改推送时间和数量？

A: 
- **推送时间**：编辑 `.github/workflows/daily-digest.yml` 中的 `cron` 表达式
- **推送数量**：编辑 `config.yaml` 中的 `max_articles_for_primary_card`
- **AI4S/通用AI比例**：编辑 `main.py` 中 `_select_diverse` 函数的配额
